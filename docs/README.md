# Documentation

This directory contains the project's research design, data provenance records, methodological specifications, and validation notes.

## Documentation map

- `research_design/`: research questions, scope, hypotheses or propositions, and analytical boundaries.
- `data/`: dataset inventory, source metadata, access conditions, and data dictionaries.
- `methodology/`: network definitions, statistical procedures, and robustness protocols.

Documentation should distinguish planned procedures from completed work. Do not report empirical findings before the corresponding analysis has been run and validated.
