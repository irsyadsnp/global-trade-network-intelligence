# Methodology Documentation

This folder records reproducible analytical specifications.

Planned topics:
- Definition of nodes, directed edges, and edge weights
- Country and industry aggregation rules
- Network construction from input-output or bilateral trade data
- Centrality and community-detection procedures
- Temporal comparison and uncertainty
- Sensitivity, robustness, and validation checks

Trade flows and inter-country input-output relationships must be defined separately. Measures of network centrality should not automatically be interpreted as causal influence or overall economic importance.
